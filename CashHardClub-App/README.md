# Cash Hard Club — official mobile app

iOS + Android app for **CASH HARD CLUB** (cashhardclub.com). Built with Expo (React Native, TypeScript) and shipped from Windows with EAS Build / EAS Submit. Bundle ID / package: `com.cashhardclub.app`.

**v1 (launch):** native shop (catalog from `cashhardclub.com/products.json`, live stock from the Squarespace store), checkout in the platform's in-app browser on the official Squarespace store, events & tickets (`cashhardclub.com/events.json`), opt-in drop alerts (OneSignal, owner-friendly dashboard), saved pieces, club links.
**v1.1 (≤30 days after launch):** members / loyalty — see `docs/10-ARCHITECTURE-V1.1.md`.

## Quick start (Windows)

```powershell
npm install
npx expo start          # press a = Android emulator; scan the QR with Expo Go on your iPhone
npm run typecheck       # TypeScript
npm run doctor          # Expo project health
```

Push notifications need a real build (Expo Go has no OneSignal module). See `docs/03-BUILD-AND-TEST.md`.

## Project layout

```
app/                    screens (Expo Router). (tabs)/ = Shop, Events, Alerts, Club
src/components/         brand UI (gold button, product/event cards, grain overlay, text styles)
src/data/               catalog + events loaders, live-stock enrichment, saved items, ContentProvider
src/lib/                in-app browser, push (OneSignal), deep-link routing, formatting, secure storage
src/theme/              design tokens (mirrored from the website) and the responsive layout hook
assets/                 icons, splash, notification icon, grain (generated by `npm run assets`)
assets/source/          the CHC monogram (SVG + PNG, gold and white) and wordmark the icon pipeline starts from
store/                  Play icon, feature graphic, screenshots (after `npm run screenshots`)
scripts/                generate-assets, screenshots, sync-content
plugins/                one tiny Expo config plugin (OneSignal launch-URL handling on Android)
docs/                   everything above
```

## Moving this folder into its own repository

This folder was created inside the website repo because the GitHub app could not create repositories. Do this once:

1. On GitHub click **New repository** → name `CashHardClub-App` → Private → **Create repository** (no README, no .gitignore).
2. In PowerShell:
   ```powershell
   cd path\to\CashHardClub
   git subtree split --prefix=CashHardClub-App -b app-split      # keeps this folder's history
   git clone -b app-split . ..\CashHardClub-App                   # standalone copy
   cd ..\CashHardClub-App
   git branch -M main
   git remote set-url origin https://github.com/adamrutrut-eng/CashHardClub-App.git
   git push -u origin main
   ```
3. Back in the website repo, delete the `CashHardClub-App` folder and commit, so the website stays clean.

## Content the app reads (no app update needed to change it)

- `https://cashhardclub.com/products.json` — the catalog (already maintained for the website)
- `https://cashhardclub.com/events.json` — events and drops (new; format documented inside the file)
- `https://shopcashhardclub.squarespace.com/store-MFHja?format=json` — live stock (best effort)

Run `npm run sync:content` before each store build so the bundled offline snapshot is current.
