# docs/legal — signed documents and dated screenshots

Kept off the public website by the `/CashHardClub-App/*` rule in `_redirects`; the GitHub repo must also be private before this file is committed. `_redirects` only protects the Netlify site, and a public GitHub repo would publish everything here, along with docs 11 and 12. Signed PDFs (`docs/legal/*.pdf`) are git-ignored, so keep a backup copy outside git as well.

- `authorization-letter-signed.pdf` — the signed letter from doc 12, Part 1 (Gate 0.1). Nothing that says the app is published "on behalf of" the owners goes live before this file exists.
- `terms-<version>-<platform>.png` — a dated screenshot of the one-time Terms screen for each `TERMS_VERSION` (e.g. `terms-2026-09-29-ios.png`, `terms-2026-09-29-android.png`).
